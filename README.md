# YKBI Pilates

Live app: **https://aigencycraft.github.io/ykbi-pilates/**

Pilates-first fitness tracker. Sign in with Google or email to log Mat, Reformer, Cadillac and Chair sessions, track holds and spring settings, and follow your progress. Data is stored in Supabase and each account only sees its own data.

This repository holds the built website only; the source code lives in a private repository.
